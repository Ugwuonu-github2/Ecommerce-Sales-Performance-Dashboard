# 📊 E-Commerce Sales Performance Dashboard

> An interactive Business Intelligence dashboard built in Microsoft Excel to transform raw e-commerce transaction data into actionable business insights through data cleaning, analysis, and visualization.

---

## 📌 Project Overview

Data-driven decision-making is essential for modern businesses. However, raw transactional data often contains little value until it is cleaned, analyzed, and presented in a meaningful way.

This project demonstrates how Microsoft Excel can be used as a Business Intelligence (BI) tool to transform over **500,000 e-commerce transaction records** into an interactive executive dashboard. Using Power Query, Pivot Tables, Pivot Charts, KPI Cards, and Slicers, the dashboard enables business stakeholders to monitor sales performance, identify trends, and make informed decisions.

---

## ⭐ Project Highlights

- Analyzed over **500,000** e-commerce transactions.
- Built an interactive executive dashboard using Microsoft Excel.
- Developed KPI cards to monitor key business metrics.
- Performed data cleaning and transformation using Power Query.
- Created dynamic Pivot Tables and Pivot Charts.
- Added interactive slicers for real-time filtering.
- Delivered actionable business insights through effective data visualization.

---

## 🎯 Business Problem

Large volumes of sales data can make it difficult for organizations to identify meaningful patterns and performance trends. Without effective reporting, decision-makers struggle to answer important business questions regarding customers, products, revenue, and sales performance.

This dashboard addresses that challenge by presenting key performance indicators and visual insights in a single, interactive report.

---

## ❓Business Questions Addressed

This project answers several important business questions:

- What is the total revenue generated?
- How many customer orders were processed?
- How many unique customers made purchases?
- Which products generated the highest revenue?
- Who are the highest-value customers?
- Which countries contributed the most revenue?
- How did monthly revenue change over time?
- Which weekdays generated the highest sales?
- How can sales be explored dynamically using filters?

## 🗂 Dataset Information

**Dataset:** Online Retail II

The dataset contains transactional records from a UK-based online retailer, including:

- Invoice Number
- Invoice Date
- Product Description
- Quantity Sold
- Unit Price
- Customer ID
- Country

The dataset was cleaned and transformed before analysis to ensure accurate reporting.

---

## 🧹 Data Cleaning & Preparation

The following preprocessing steps were carried out before building the dashboard:

- Removed duplicate records
- Excluded cancelled transactions
- Removed invalid quantities and prices
- Created a Revenue column
- Extracted Month, Year, and Weekday from transaction dates
- Structured the dataset for Pivot Table analysis
- Verified data consistency and quality

---

## 💡 Key Insights

The analysis revealed several important business insights:

- The **United Kingdom** generated the highest revenue.
- A relatively small group of customers contributed a significant share of total sales.
- Sales exhibited noticeable seasonal trends across the year.
- A small number of products accounted for a large proportion of overall revenue.
- Interactive filters enable users to analyze performance across different countries, time periods, and customer segments.
